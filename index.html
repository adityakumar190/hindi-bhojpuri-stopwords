Abstract

Stop words are high-frequency function words, such as conjunctions, pronouns, postpositions and auxiliary verbs, that are commonly removed during text preprocessing in Natural Language Processing (NLP). This assignment documents stop words for two Indo-Aryan languages, Hindi and Bhojpuri. For each language, a list of 100 unique stop words was compiled and written in Roman (English) letters, transliterated from the Devanagari script. Each list is stored in a Python file named after its language and published in a GitHub repository, with this webpage hosted through GitHub Pages. Comparing the two lists shows that 30 words appear in both, mainly postpositions, interrogatives and quantifiers, while pronouns and auxiliary verbs differ more. Because Roman spelling is not standardised, any practical list needs to allow for variant forms.

1Introduction

Text written in any language contains a large number of words that occur very frequently but contribute little to the meaning of a sentence. These words, known as stop words, include conjunctions, pronouns, postpositions, auxiliary verbs and words of negation. In English, and, the and is are typical examples; in Hindi, aur (and) and hai (is) play the same role.

In Natural Language Processing (NLP), stop words are commonly removed during text preprocessing. Doing so reduces the size of the vocabulary, lowers noise in the data, and allows tasks such as text classification, information retrieval and topic modelling to concentrate on content-bearing words.

Hindi and Bhojpuri both belong to the Indo-Aryan branch of the Indo-European language family and are traditionally written in the Devanagari script. Because the two languages share part of their vocabulary and grammar while differing in many everyday forms, their function words offer a useful basis for comparison. This assignment therefore compiles and presents a stop-word list for each language.

2Objectives

  1. To compile a list of 100 unique stop words for Hindi and a list of 100 unique stop words for Bhojpuri.
  2. To write the words in Roman (English) letters so that they can be used in any standard text-processing environment.
  3. To store each list in a separate Python file named after its language, following the prescribed file format.
  4. To publish the files in a public GitHub repository and present the work on a webpage hosted through GitHub Pages.
  5. To compare the two lists and note the similarities and differences between them.

4Method

The lists were prepared in the following stages.

  1. Selection. Common function words were chosen for each language from the main grammatical groups: conjunctions, pronouns, postpositions, auxiliary verbs, interrogatives, negation and quantifiers.
  2. Romanisation. Each word was written in Roman letters using commonly seen spellings (for example, aur, tha and hai). Variant spellings of a word, such as nahi and nahin, were both included where relevant.
  3. Verification. Each list was checked to confirm that it contains exactly 100 entries and that no word is repeated within it.
  4. File preparation. The lists were saved as Python lists in files named hindi_stopwords.py and bhojpuri_stopwords.py, each beginning with the prescribed header describing the topic, authors, semester and affiliation.
  5. Publication. The files were uploaded to a GitHub repository, and this webpage was published with GitHub Pages, with each file name linked to its page in the repository.

7Observations

A comparison of the two lists gives the following observations.

  • Shared words. 30 words appear in both lists. They include the postpositions ke, mein, se and par, the interrogatives kaun, kaise, kab and kahan, and quantifiers such as bahut, kuch and sab.
  • Pronouns. The pronoun forms differ. The Hindi list contains main, hum, tum and aap, whereas the Bhojpuri list contains ham, hamni, tu, tohni and raua.
  • Auxiliary verbs. Hindi forms such as hai, hain, tha and thi correspond to Bhojpuri forms such as ba, bate, bani and rahal.
  • Spelling. Because Roman spelling is not standardised, closely related forms occur in the lists, such as nahi and nahin.

8Limitations

  • The lists are illustrative and are not exhaustive. A larger list could be built from a text corpus by counting word frequencies.
  • Roman spellings of Hindi and Bhojpuri words vary between writers, so a word may appear in more than one form.
  • Bhojpuri is spoken across several regions, and some forms may differ between speakers.
  • Words such as negations can carry meaning in certain tasks, such as sentiment analysis, so removing stop words should be tested for each task.

9Conclusion

This assignment produced two stop-word lists of 100 words each, one for Hindi and one for Bhojpuri, written in Roman letters and published as Python files in a GitHub repository. The comparison shows that the two languages share a core of function words, particularly postpositions, interrogatives and quantifiers, while their pronouns and auxiliary verbs differ. The lists can be used directly for text preprocessing and can be extended with further words and spelling variants.
