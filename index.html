Abstract

This project documents the compilation of stop-word lists for two Indo-Aryan languages, Hindi and Bhojpuri, to aid in Natural Language Processing (NLP) text preprocessing. For each language, 100 unique stop words were compiled in Roman letters, transliterated from Devanagari, and deployed as Python files in a GitHub repository with an accompanying GitHub Pages website. The two lists were kept mutually exclusive: words common to both languages were assigned to a single list, ensuring the alternative list utilized its own distinctive forms. Additionally, the dataset accounts for variation in Romanized spellings to maximize practical utility.

1Introduction

Text written in any language contains a large number of words that occur very frequently but contribute little to the meaning of a sentence. These words, known as stop words, include conjunctions, pronouns, postpositions, auxiliary verbs and words of negation. In English, and, the and is are typical examples; in Hindi, aur (and) and hai (is) play the same role.

In Natural Language Processing (NLP), stop words are commonly removed during text preprocessing. Doing so reduces the size of the vocabulary, lowers noise in the data, and allows tasks such as text classification, information retrieval and topic modelling to concentrate on content-bearing words.

Hindi and Bhojpuri both belong to the Indo-Aryan branch of the Indo-European language family and are traditionally written in the Devanagari script. Because the two languages share part of their vocabulary and grammar while differing in many everyday forms, their function words offer a useful basis for comparison. This assignment therefore compiles and presents a stop-word list for each language.

2Objectives

  1. To compile a list of 100 unique stop words for Hindi and a list of 100 unique stop words for Bhojpuri, with no word common to the two lists.
  2. To write the words in Roman (English) letters so that they can be used in any standard text-processing environment.
  3. To store each list in a separate Python file named after its language, following the prescribed file format.
  4. To publish the files in a public GitHub repository and present the work on a webpage hosted through GitHub Pages.
  5. To examine how the function-word forms of the two languages differ, using the two lists as evidence.

4Method

The lists were prepared in the following stages.

  1. Selection: Common function words were chosen for each language from the main grammatical groups: conjunctions, pronouns, postpositions, auxiliary verbs, interrogatives, negation and quantifiers. Where a word is common to both languages, it was placed in only one list, and the other list uses its own distinctive form.
  2. Romanisation: Each word was written in Roman letters using commonly seen spellings (for example, aur, tha and hai). Variant spellings of a word, such as nahi and nahin, were both included where relevant.
  3. Verification: Each list was checked to confirm that it contains exactly 100 entries and that no word is repeated within it or appears in the other list.
  4. File preparation: The lists were saved as Python lists in files named hindi_stopwords.py and bhojpuri_stopwords.py, each beginning with the prescribed header describing the topic, authors, semester and affiliation.
  5. Publication: The files were uploaded to a GitHub repository, and this webpage was published with GitHub Pages.

7Observations

A comparison of the two lists gives the following observations.

  • No common words. The two lists share no word. Where Hindi and Bhojpuri use the same word, it appears in the Hindi list only, and the Bhojpuri list uses its own form.
  • Postpositions. The Hindi list contains ka, ke, ki, mein, se and par, whereas the Bhojpuri list contains me, pe, sein, le, khatir and sange.
  • Pronouns. The Hindi list contains main, hum, tum and aap, whereas the Bhojpuri list contains ham, hamni, tu, tohni and raua.
  • Auxiliary verbs. Hindi forms such as hai, hain, tha and thi correspond to Bhojpuri forms such as ba, bate, bani and rahal.
  • Spelling. Because Roman spelling is not standardised, closely related forms occur within the lists, such as nahi and nahin in Hindi.

8Limitations

  • The lists are illustrative and are not exhaustive. A larger list could be built from a text corpus by counting word frequencies.
  • Because the two lists do not overlap, a word used in both languages appears in one list only. A combined list may be preferable for tasks that process both languages together.
  • Roman spellings of Hindi and Bhojpuri words vary between writers, so a word may appear in more than one form.
  • Bhojpuri is spoken across several regions, and some forms may differ between speakers.
  • Words such as negations can carry meaning in certain tasks, such as sentiment analysis, so removing stop words should be tested for each task.

9Conclusion

This assignment produced two stop-word lists of 100 words each, one for Hindi and one for Bhojpuri, written in Roman letters and published as Python files in a GitHub repository. The lists were compiled so that no word appears in both, which brings out the distinctive postpositions, pronouns and auxiliary verbs of each language. They can be used directly for text preprocessing and can be extended with further words and spelling variants.
