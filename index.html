Abstract

This project documents the compilation of stop-word lists for two Indo-Aryan languages, Hindi and Bhojpuri, to support text preprocessing in Natural Language Processing (NLP). For each language, 100 unique stop words were compiled in Roman letters, transliterated from Devanagari, and stored as Python files in a GitHub repository with an accompanying GitHub Pages website. The two lists are mutually exclusive: a word common to both languages is placed in one list only, and the other list uses its own distinctive form. Common variant spellings are included to improve practical usefulness.

1Introduction

Text in any language contains many words that occur very frequently but contribute little to the meaning of a sentence. These words, known as stop words, include conjunctions, pronouns, postpositions, and auxiliary verbs. In English, and, the and is are typical examples; in Hindi, aur (and) and hai (is) play the same role.

In NLP, stop words are commonly removed during preprocessing. Doing so reduces the size of the vocabulary and the noise in the data, and lets tasks such as text classification, information retrieval and topic modelling concentrate on content-bearing words.

Hindi and Bhojpuri both belong to the Indo-Aryan branch of the Indo-European language family and are traditionally written in the Devanagari script. Because the two languages share part of their vocabulary and grammar while differing in many everyday forms, their function words offer a useful basis for comparison. This assignment therefore compiles and presents a stop-word list for each language.

2Objectives

  1. To compile 100 unique stop words for Hindi and 100 for Bhojpuri, with no word common to the two lists.
  2. To write the words in Roman (English) letters so that they can be used in any standard text-processing environment.
  3. To store each list in a separate Python file named after its language.
  4. To publish the files in a public GitHub repository and present the work on a webpage hosted through GitHub Pages.
  5. To examine how the function-word forms of the two languages differ, using the two lists as evidence.

4Method

The lists were prepared in five stages.

  1. Selection: Common function words were chosen for each language from six grammatical groups: conjunctions, pronouns, postpositions, auxiliary verbs, interrogatives, and negations and quantifiers. A word common to both languages was placed in one list only, and the other list uses its own distinctive form.
  2. Romanisation: Each word was written in Roman letters using commonly seen spellings (for example, aur, tha and hai). Variant spellings, such as nahi and nahin, were both included where relevant.
  3. Verification: Each list was checked to confirm that it has exactly 100 entries, that no word is repeated within it, and that no word appears in the other list.
  4. File preparation: The lists were saved as Python lists in hindi_stopwords.py and bhojpuri_stopwords.py.
  5. Publication: The files were uploaded to a GitHub repository, and this webpage was published with GitHub Pages.

      • No common words: The two lists share no word. Where Hindi and Bhojpuri use the same word, it appears in the Hindi list only, and the Bhojpuri list uses its own form.
      • Postpositions and verbs: Hindi marks relations with ka, ke, mein and par, and Bhojpuri with me, pe, sein and khatir. Hindi hai corresponds to Bhojpuri ba, and Hindi tha to Bhojpuri rahal.
      • Verb forms: The Bhojpuri list has more auxiliary-verb entries than the Hindi list (27 against 22), because it records several forms of “to be” (ba, bate, bani, bade) and of the past (rahal, rahlas, rahlan). The Hindi list has more pronoun entries (33 against 27), including the possessives mera, hamara, tumhara and aapka with their gender forms.
      • Spelling: Because Roman spelling is not standardised, closely related forms occur within the lists, such as nahi and nahin in Hindi.

      8Demonstration

      The tool below applies the lists to a sentence typed in Roman letters. Words found in the Hindi list are shaded blue, and words found in the Bhojpuri list are shaded green with a dashed underline. All other words are kept. Matching ignores capital letters.

      The same step in Python, using the files in this repository:

      import re
from hindi_stopwords import hindi_stopwords
from bhojpuri_stopwords import bhojpuri_stopwords

stop = set(hindi_stopwords) | set(bhojpuri_stopwords)
text = "mera gaon Bihar mein hai"
tokens = re.findall(r"[a-z]+", text.lower())
print([t for t in tokens if t not in stop])   # ['gaon', 'bihar']

      Words such as karte and wahan are not in the lists, so they are kept. This shows why the lists are a starting point and not a complete resource.

      9Limitations

      • The lists are illustrative and not exhaustive. A larger list could be built from a text corpus by counting word frequencies.
      • Because the lists do not overlap, a word used in both languages appears in one list only. For text that mixes both languages, the two lists should be combined, as in the example above.
      • Roman spellings of Hindi and Bhojpuri words vary between writers, so a word may appear in more than one form.
      • Bhojpuri is spoken across several regions, and some forms may differ between speakers.
      • Negations can carry meaning in some tasks, such as sentiment analysis, so stop-word removal should be tested for each task.

      10Conclusion

      This assignment produced two stop-word lists of 100 words each, one for Hindi and one for Bhojpuri, written in Roman letters and published as Python files in a GitHub repository. Because no word appears in both lists, they bring out the distinctive postpositions, pronouns and auxiliary verbs of each language. They can be used directly for text preprocessing and extended with further words and spelling variants.
